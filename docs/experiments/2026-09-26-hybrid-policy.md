# 성능 모델과 측정 테이블의 혼합 선택 정책 (2026-09-26)

**질문.** 성능 모델은 실행 시간 예측 오차(중앙값 2.3~12.3%)는 목표 안이지만, 최악의 경우 최적보다 24~66% 느린 커널을 골라 선택 품질 기준(손실 중앙값 ≤ 5%, 최댓값 ≤ 15%)을 통과하지 못했다([검증표](../plan/2026-09-22-model-validation.md)). 최악 사례는 모두 같은 모양이었다. 모델이 분할하지 않는 변형(`fa2_paged`)을 분할 변형보다 몇 % 빠르다고 예측했지만, 실측에서는 분할 변형이 20~60% 빨랐다. 예측 시간이 몇 % 차이밖에 나지 않는 후보들 사이의 순위는 모델이 잘 가리지 못한다.

**방법.** 혼합 정책(`HybridPolicy`, `kernelscope/model/hybrid.py`)은 모델의 예측 순위를 쓰되, 가장 가까운 실측 조건에서 가장 빨랐던 변형을 모델이 자기 최선의 (1 + δ)배 이내로 예측하면 그 변형을 고른다. δ = 0이면 모델 정책, δ = ∞이면 측정 테이블 정책과 같다. 평가는 GPU 없이 기록된 RTX 4090 측정값으로 한다(`python -m scripts.evaluate_hybrid`). 각 검증 조건의 테이블은 **그 조건을 제외한** 나머지 실측 조건(같은 캐시 상태·같은 KV 캐시 형식, 균일·혼합 길이 전부)으로 만든다(leave-one-out). 손실은 고른 변형의 실측 시간 ÷ 같은 조건에서 가장 빠른 변형의 실측 시간 − 1이다.

**해석.**

- δ = 0.2인 혼합 정책은 서빙에 쓰는 cold 상태의 세 검증 집합 모두에서 선택 품질 기준을 통과한다. 최악 손실은 V1 **1.97%**, V5 **7.54%**, V6 **10.90%**이며 15%를 넘는 조건이 없다. 모델 단독(24.25% / 66.29% / 24.52%)과 테이블 단독(50.37% / 66.07% / 100.66%)은 모두 통과하지 못했다.
- 두 근거를 합치는 것이 각각보다 낫다. 테이블 단독은 측정 격자의 가장자리(가장 가까운 실측 조건이 멀 때)에서 크게 틀리고, 모델 단독은 예측 시간이 비슷한 후보 사이의 순위를 틀린다. 혼합 정책은 모델이 후보를 좁히고 테이블이 근소한 차이를 판정하는 구조다.
- δ는 0.2 근방이 좋다. 0.05~0.1은 V1·V5의 최악 사례(예측 차이 13~15%)를 잡지 못하고, 0.5는 테이블의 오류를 다시 끌어들인다. 0.01 간격으로 다시 훑으면 세 집합이 모두 통과하는 구간은 δ ≈ 0.16~0.32이고(0.15 이하: V5 최악 24.7%, 0.35 이상: V1 16.9%·V5 16.1%), 0.2는 그 가운데다. 단일 값이 아니라 이 구간이 결론이다.
- warm 상태(V1)에서는 어떤 정책도 기준을 통과하지 못한다. 최악 조건(B = 32, L = 512, 연속 KV)은 기본 휴리스틱도 41.7% 손실을 내는 조건으로, 모델이 분할하지 않는 변형의 시간을 절반으로 과소 예측한다. 서빙 엔진은 cold 가정을 쓰므로 이번 결정에는 영향이 없지만, 모델의 warm 대역폭 항은 향후 과제다.
- **주의.** leave-one-out 테이블은 검증 조건과 같은 측정 격자의 다른 조건을 쓴다. V5처럼 헤드 구성이 다른 모델을 서빙하려면 그 헤드 구성의 격자를 먼저 측정해야 이 결과가 성립한다. 측정 격자가 없는 헤드 구성에서는 혼합 정책이 모델 정책으로 되돌아간다(`HybridPolicy`는 테이블이 그 헤드 구성을 덮지 않으면 테이블을 조회하지 않는다). 또한 V6의 혼합 길이 격자는 (배치, 최대 길이, 평균 길이)의 로그 특징이 같은 '쌍둥이' 조건을 많이 포함해(219개 중 39개가 거리 0의 이웃을 가짐), 손으로 고른 운영용 테이블보다 이웃이 촘촘하다. 쌍둥이끼리 최적 변형이 다른 경우도 있어 손실을 인위적으로 낮추지는 않지만, 격자가 성긴 테이블에서는 V6 수치가 이보다 나쁠 수 있다.

**조치.** `kernelscope serve run --policy hybrid:<table.csv>:0.2`로 실제 LLM 생성에서 검증했다(2026-10-02, [결과](2026-10-02-hybrid-validation.md)). 이 문서의 수치는 `kernelscope verify`의 `model.hybrid_*` 항목으로 재계산된다.
